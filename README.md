# Alessandro Pedrosa · Construção Civil — site de demonstração

Proposta de site (HTML, CSS e JavaScript puros, sem build). A obra é um vídeo sem som que avança conforme a rolagem.

- Abrir: sirva a pasta com um servidor que aceite *Range* (ex.: Vercel, Netlify, `npx serve`). Abrir o `index.html` direto do disco não rola o vídeo.
- Imagens e vídeos são ilustrativos (gerados por IA / banco de vídeos). Trocar pelas fotos e vídeos reais das obras antes de publicar.
- `vercel.json` já traz o cache longo para `fonts/`, `img/` e `video/`.
